# Bundled DOS packages

`c602-runtime.zip` is an operator-supplied original Software602 Calc602 runtime,
prepared with the owner's approval from `AR6_Archive_Format/test/C602`.
It contains only C602.EXE, C602.DRV, C602.HLP, the original FON fonts and DST
printer drivers. Original copyright notices remain in the program/help.
It deliberately excludes C602.CFG, PRIKLADY, spreadsheets, macros and all
working/test documents. New settings are created in the user's DOS overlay.
The DOS manifest's `file` field uses the existing bounded local-package loader.

`UNARJ241.EXE` is the existing original DOS UnARJ package used by UTILS; its
extraction and licence retention are defined by that package's archive recipe.
